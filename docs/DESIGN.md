# Mira 设计方向

## Design Read

面向 22–32 岁城市用户的夜间陪伴型 Web App，采用“深夜电台 + 私人手帐”视觉语言，以暗色雾面材质和单一暖珊瑚强调色构建安全、私密、安静但不阴郁的氛围。

## 视觉规则

- 主背景：墨青黑，允许极轻噪点和低对比光晕，不使用紫色 AI 渐变。
- 强调色：暖珊瑚 `#df6d52`，全站只用一个主强调色。
- 字体：系统中文字体优先，保证中文可读；标题使用紧凑字距，正文行高 1.7。
- 圆角：卡片 16px、面板 24px、按钮使用全圆角；全站保持一致。
- 卡片：只在层级需要时使用，列表优先用分隔线和留白。
- 动效：回应出现、照片到达、记忆星图节点聚焦；尊重 `prefers-reduced-motion`。
- 图像：人像与生活场景照片用于建立关系感，不伪造真实用户；所有图片保留 alt 与来源说明。

## 页面结构

### 桌面

- 左侧 72px 角色轨道
- 中间会话主区
- 右侧 320px 当前角色的记忆 / 相册 / 氛围控制

### 移动

- 顶栏：角色、在线状态、更多
- 主区：聊天
- 底部：对话 / 记忆 / 相册 / 设置四栏导航
- 输入框固定在安全区上方

## 核心组件

- PersonaOrbit：角色切换，不用普通头像横排。
- MessageStream：用户、角色、系统事件和照片混合流。
- Composer：文本、情绪快捷语、发送、停止。
- MemoryConstellation：节点、连线、筛选和详情抽屉。
- MemoryCard：类型、内容、证据、编辑、删除。
- AlbumGrid：图像、场景标签、收藏和灯箱。
- SafetyBanner：危机援助与过度依赖提醒。
- AmbientPlayer：播放/暂停、音量、生成中的声波可视化。

## 状态要求

- 首次加载：骨架屏与角色数据的实际形状一致。
- 流式回复：显示可中断状态，不显示假进度。
- 空记忆：解释“你告诉 TA 的偏好会出现在这里”。
- 空相册：解释照片会在聊天语境中自然出现。
- API 错误：设置页内联错误，并保留 demo 降级入口。
- 危机状态：最高视觉优先级，但不使用刺眼全屏警告。

## 禁止

- 紫色霓虹、玻璃卡片堆叠、居中营销式 Hero。
- 过多 pill、badge、渐变文字。
- 每个标题上方都放 eyebrow。
- 首屏用假截图或伪数据撑满。
- 将 AI 包装为真人或声称医疗能力。
