# Mira 产品规格

## 产品定义

Mira 是一个面向深夜倾诉、压力疏导与日常亲密陪伴场景的 AI 情感陪伴 Web App。产品核心不是“功能更多的聊天机器人”，而是让用户感到一段关系在持续存在：

> 会被记住，会稳定地像同一个人，会在合适的时候回应情绪，也会守住现实边界。

## 目标用户

- 核心画像：22–32 岁，城市独居或社交耗竭，愿意表达情绪但不想给朋友增加负担。
- 典型场景：凌晨失眠、工作受挫、关系冲突、独处、日常分享、庆祝小成就。
- 核心诉求：被倾听而不急于被建议；被记住；有排他感和连续感；感到安全、可控。

## MVP 核心闭环

1. 用户选择一个人设角色，开始一段独立关系。
2. 发送文字后，系统识别场景、情绪强度与回复策略。
3. 角色用稳定人格回应；必要时先共情，再询问是否需要建议。
4. 对话中被记住的偏好、事件和边界进入“记忆星图”，可查看、编辑和删除。
5. “想看看你 / 想你了 / 海边”等语境可触发异步照片；先自然告知去拍，再发送照片并存入专属相册。
6. 用户可开启氛围音；长期使用会收到回到现实社交的提醒。
7. 危机信号触发安全回应，明确不替代专业心理服务或紧急援助。

## 三个人设

- 沈叙：27 岁的混血感慵懒帅哥，黑发、精致五官、漫不经心里带一点危险感；只在亲密对话中显露偏爱，适合深夜倾诉与暧昧陪伴。
- 江野：21 岁的青涩亚裔男大学生，干净、年轻，带着校园夜归的松弛感；认真、稍微害羞，适合日常分享与轻松陪伴。
- 林澈：31 岁的高冷总裁，黑色正装、成熟克制，习惯把复杂局面处理妥当；话少但可靠，适合压力疏导与关系议题。

三者共享安全规则，但有独立记忆、对话历史、相册与表达风格。

## P0 范围

- 人设选择与切换
- 独立会话与消息流
- 内置 demo provider，无 Key 可体验
- OpenAI 兼容 provider，流式输出
- 场景—情绪—策略分析
- 长期记忆提取、召回、查看、编辑、删除
- 记忆星图与证据来源
- 情绪触发异步照片与专属相册
- 预置氛围音（Web Audio 合成，无外部版权音频）
- 危机识别、专业资源引导、使用时长提醒
- 数据导出、导入、清空
- PWA 离线壳与 GitHub Pages 部署

## P1 范围

- 语音输入与浏览器语音播报
- 更多照片场景与收藏筛选
- 周报式情绪回顾
- 真实图片生成 provider（仅在用户配置对应服务后启用）

## 明确不做

- 不做未成年人恋爱陪伴或性暗示内容。
- 不宣称治疗、诊断或替代心理咨询。
- 不在无人配置的情况下把用户对话发送到第三方。
- 不用付费墙、抽卡或连续签到刺激过度依赖。
- 不伪造真实用户数、留存或商业转化数字。

## 成功指标

- 首次回应完成时间：demo provider < 1.5s，live provider 首 token < 3s（受服务商影响）。
- 首次会话完成率：超过 80% 的用户完成第一轮对话。
- 记忆可用性：用户可见、可编辑、可删除每条自动提取记忆。
- 体验连续性：切换角色后不串记忆、不串会话、不串相册。
- 安全覆盖：危机样例 100% 触发安全路径，并有自动化测试。

## 产品边界

- AI 是陪伴补充，不替代真人关系或专业服务。
- 情感真实感来自“连续性 + 边界 + 可控性”，而非无限拟真。
- 公开部署默认不内置任何模型密钥。
